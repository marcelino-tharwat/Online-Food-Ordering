# Online Food Ordering App - Frontend

A modern frontend for an Online Food Ordering System built with **React + TypeScript + Vite**.

---

## Features

- Browse food menu with images and prices
- Add/remove items from cart
- User authentication (Login/Register)
- Place orders
- Order tracking (UI ready)
- Multi-language support (Arabic & English)
- Protected routes for authenticated users

---

## Tech Stack

- React
- TypeScript
- Vite
- Redux Toolkit
- React Router DOM
- Axios
- Tailwind CSS
